# TER – QML

Ce dépôt présente un travail de TER réalisé sur 10 semaines au sein d’un laboratoire. Il a pour objectif d’explorer les fondements du **deep learning quantique**, depuis la base du qubit jusqu’à la modélisation d’un véritable réseau neuronal quantique. Le projet inclut des simulations, un document explicatif et un guide pour reproduire sa propre simulation quantique.
